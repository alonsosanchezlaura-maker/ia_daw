# Práctica IA (RA4 · a) — Automatización y optimización

## 1) Proceso elegido
- Nombre del proceso: Clasificación de tickets de soporte técnico
- Contexto (empresa/servicio web/IT): Plataforma de soporte de una empresa de servicios TI o software (SaaS)
- Rol/es implicados:
Cliente / usuario del servicio
Agente de soporte técnico
Equipo especializado (redes, software, facturación)

## 2) ANTES (sin IA)
- Pasos (5–7):
  1. El usuario envía un ticket a través del formulario web o correo electrónico.
  2. Un agente de soporte revisa manualmente el mensaje.
  3. El agente analiza el problema descrito por el usuario.
  4. Se clasifica el ticket (error técnico, acceso, facturación, etc.).
  5. Se asigna al departamento correspondiente.
  6. El equipo técnico revisa el ticket y prepara una respuesta.
  7. Se responde al cliente y se cierra el ticket.
- Tiempo aproximado por caso: Entre 15 y 25 minutos por ticket, dependiendo de la complejidad.
- Problemas / cuellos de botella:
Clasificación manual lenta.
Posibles errores al asignar tickets al equipo equivocado.
Acumulación de tickets en horas de alta demanda.
Muchas consultas repetitivas (preguntas frecuentes).

## 3) DESPUÉS (con IA)
- ¿Qué automatiza la IA?
  La IA puede automatizar:
Clasificación automática de tickets mediante análisis de texto.
Priorización de incidencias según urgencia o impacto.
Respuestas automáticas a preguntas frecuentes mediante chatbot.

- ¿Qué queda para humanos?
Resolver problemas complejos o técnicos.
Validar respuestas automáticas en casos dudosos.
Tomar decisiones críticas o excepcionales.

- Datos necesarios (tipos de datos, sin datos personales):
Tipos de datos utilizados:
Texto de tickets de soporte
Historial de incidencias resueltas
Categorías de problemas
Base de conocimiento o FAQ
(No se usan datos personales sensibles).

- Modelo/técnica (NLP, clasificación, recomendación, visión, etc.):
NLP (Procesamiento de Lenguaje Natural)
Clasificación de texto
Chatbots basados en IA
